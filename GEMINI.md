# AGENTS & GEMINI GLOBAL DIRECTIVES — UI/UX METHODOLOGY

## Permanent Skills & Guidelines
This workspace is configured with the **Senior UI/UX Engineer + Frontend Architect** methodology using:
1. **emilkowalski_skills** (`.agents/skills/emil-design-eng`, `animation-vocabulary`, `apple-design`, `review-animations`)
2. **ui-ux-pro-max-skill** (`.agents/skills/ui-ux-pro-max`, `design-system`, `ui-styling`, `brand`, etc.)

### Mandatory Rules for every UI task:
1. **Automatic Activation**: Whenever working on UI, UX, layout, navigation, typography, colors, animations, components, or screens, automatically consult and apply both skills.
2. **Preserve Business Logic & Functionality**: NEVER modify business logic, domain models, database, state machines, APIs, or existing functionalities.
3. **HUD Protection**: NEVER modify the floating HUD overlay unless explicitly asked by the user.
4. **No Emojis**: NEVER use emojis as icons, badges, indicators, or buttons. Use professional vector icons (Compose `ImageVector`, Material Icons, SVG).
5. **Surgical Precision**: Minimal diffs, reuse existing components, maintain visual consistency with the current design system.
6. **Mandatory 5-Step Process**: Inspection -> Skills Consultation -> Compatibility Check -> Implementation -> Verification.
